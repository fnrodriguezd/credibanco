09 — El MVP

Tres componentes para empezar

El MVP concentra los componentes que más se repiten y que tienen mayor impacto en la experiencia.

Button
Continuar
Cancelar
Continuar
3 tipos (Primary, Secondary, Tertiary) · 2 tamaños · Estados con contraste verificado (incl. Disabled ajustado a WCAG AA) · Auto Layout · Variables · Naming escalable
Input
Contraseña
Número de documento
El número de documento no puede quedar vacío.
5 estados (Default, Focus, Filled, Error, Disabled) · Affordance completa en los 4 bordes · Mensajes de error accionables, sin lenguaje técnico · Ícono de visibilidad de contraseña con estado visual propio · Variables
Card
Centro de ayuda
Guías y respuestas paso a paso
Componente basado en slots, reutilizable en 3 contextos del producto (navegación, selección única, selección múltiple, acción con CTA) · 4 tipos de trailing element · Elevación en vez de borde, para diferenciarlo semánticamente de una lista de opciones · Variables
El MVP establece las primeras reglas reutilizables del sistema, con decisiones de accesibilidad, semántica y tono de contenido verificadas, no solo estéticas.
